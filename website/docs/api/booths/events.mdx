These endpoints let you programmatically create booths and list all active booths for an event. This is useful for event platforms that provision booths dynamically at runtime rather than pre-configuring them through the admin panel.

## Create a Booth

Use this endpoint to create an interpretation booth for an event. Voxbento registers the booth in its live state registry so listeners can connect immediately.

```text
POST /api/events/{event_slug}/booths
```

### Authentication

A Bearer token is required. See the [Authentication guide](../authentication.mdx) for details on obtaining a token.

### Path Parameters

**`event_slug`** *(string)* — The URL slug of the event under which the booth is created, e.g. `pycon2026`. The event must already exist before you can create booths for it.

### Request Body

**`language_code`** *(string, required)* — ISO 639-1 two-letter language code in lowercase, e.g. `en`. Combined with the event slug and room ID to derive the `booth_id` and channel path.

**`room_id`** *(integer, optional)* — Numeric room ID. Room selection behaves as follows:
- If the event has no rooms, a default room is automatically created with display name specified by `room_name` (or `"Main Room"`).
- If the event has exactly one room and `room_id` is omitted, that existing room is automatically selected.
- If the event has multiple rooms, `room_id` is required; omitting it returns HTTP `400 Bad Request`.

**`language`** *(string, optional)* — Human-readable language name displayed in the UI, e.g. `"English"`. Defaults to the uppercased `language_code` if omitted.

**`room_name`** *(string, optional)* — Display name for the room if a new room is automatically created. Defaults to `"Main Room"`.

**`instance`** *(string, optional)* — Booth instance: `"primary"` (default) or `"backup"`.


### Example Request

```bash
curl -X POST https://voxbento.com/api/events/pycon2026/booths \
  -H 'Authorization: Bearer eyJ...' \
  -H 'Content-Type: application/json' \
  -d '{"language_code": "en", "room_id": 14, "language": "English"}'
```

### Example Response

A successful creation returns HTTP `201 Created` with the booth state object, including the derived WHIP and WHEP URLs.

```json
{
  "booth_id": "pycon2026-14-en",
  "event_slug": "pycon2026",
  "language_code": "en",
  "instance": "primary",
  "mediamtx_path": "pycon2026/14/en",
  "room_id": 14,
  "language": "English",
  "channel_id": "pycon2026/14/en",
  "active_interpreter_id": null,
  "handoff_state": "idle",
  "handoff_initiator_id": null,
  "broadcast_unlocked": false,
  "ingest_status": "disconnected",
  "participants": [],
  "chat_messages": [],
  "whip_url": "https://voxbento.com/pycon2026/14/en/whip",
  "whep_url": "https://voxbento.com/pycon2026/14/en/whep",
  "interpreter_invite_url": "https://voxbento.com/join/tok_123456",
  "caption_url": "wss://voxbento.com/ws/captions/pycon2026-14-en"
}
```

### Error Responses

| Status | Condition |
| --- | --- |
| `400 Bad Request` | Invalid `language_code` format, booth already exists, or event has multiple rooms and `room_id` was omitted. |
| `403 Forbidden` | Bearer token is missing or invalid. |

## List Booths for an Event

Use this endpoint to retrieve all active booths currently registered for an event. The response includes both WHIP and WHEP URLs for each booth.

```text
GET /api/events/{event_slug}/booths
```

### Authentication

A Bearer token is required.

### Path Parameters

**`event_slug`** *(string)* — The URL slug of the event whose booths you want to list.

### Example Request

```bash
curl https://voxbento.com/api/events/pycon2026/booths \
  -H 'Authorization: Bearer eyJ...'
```

### Response Fields

**`event_slug`** *(string)* — The event slug echoed from the request path.

**`booths`** *(array)* — An array of booth state objects. Each object has the same shape as the response from [GET booth state](./state.mdx).

  <details>
<summary>Booth object fields</summary>

**`booth_id`** *(string)* — Canonical booth identifier in the format `{event_slug}-{room_id}-{language_code}`.

**`event_slug`** *(string)* — The URL slug of the event.

**`language_code`** *(string)* — ISO 639-1 two-letter language code.

**`instance`** *(string)* — Booth instance: `"primary"` or `"backup"`.

**`mediamtx_path`** *(string)* — The channel path in the format `{event_slug}/{room_id}/{language_code}`.

**`room_id`** *(integer)* — Numeric room ID.

**`language`** *(string)* — Human-readable language name, e.g. `"English"`.

**`channel_id`** *(string)* — Channel path identifier matching `mediamtx_path`.

**`active_interpreter_id`** *(string | null)* — Participant ID of the currently active interpreter, or `null`.

**`handoff_state`** *(string)* — Current handoff state: `"idle"`, `"offered"`, or `"requested"`.

**`handoff_initiator_id`** *(string | null)* — Participant ID of the handoff initiator, or `null`.

**`broadcast_unlocked`** *(boolean)* — Whether broadcast lockout is bypassed.

**`ingest_status`** *(string)* — Current stream status: `"connected"` or `"disconnected"`.

**`participants`** *(array)* — All participants currently connected to the booth WebSocket.

**`chat_messages`** *(array)* — Recent chat history snapshot (capped at the last 100 messages).

**`whip_url`** *(string)* — The WHIP ingest URL for the active interpreter to publish audio.

**`whep_url`** *(string)* — The WHEP playback URL for listeners to receive audio.

**`type`** *(string)* — Channel type: `"human"` for interpreter booths or `"ai"` for automated translation streams.

**`label`** *(string)* — Human-readable display label, e.g. `"English (Human)"` or `"Spanish (AI)"`.

</details>

## Prerequisites and Behaviour Notes

:::info
The event must exist — created via the admin panel — before you can create or list booths for it via the API. Attempting to create a booth for a non-existent event slug returns a `400 Bad Request`.
:::

:::info
Booths created via this API endpoint are registered in memory and persisted to the database. Both human interpreter booths and automated translation streams appear in the list returned by `GET /api/events/{event_slug}/booths`.
:::
