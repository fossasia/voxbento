The booth state endpoint returns the live state of an interpretation booth — active interpreter, connected participants, mic status, handoff state, and stream health. Use this data to power monitoring dashboards, coordinator consoles, or integrations that need to inspect live booth status.

## Endpoint

```text
GET /api/events/{event_slug}/booths/{language_code}/state
```

## Authentication

Requires a valid token in the `Authorization: Bearer <token>` header, or passed via the `token` query parameter. Obtain tokens via `POST /api/auth/token`. See the [Authentication guide](../authentication.mdx) for details.

:::warning
Requests without valid credentials receive a `403 Forbidden` response.
:::

## Path Parameters

**`event_slug`** *(string, required)* — The event's URL slug, e.g. `pycon2026`. Must be lowercase alphanumeric with optional hyphens, maximum 64 characters.

**`language_code`** *(string, required)* — ISO 639-1 two-letter language code in lowercase, e.g. `en`. Identifies which language channel's booth to retrieve.

## Query Parameters

**`room_id`** *(integer, optional)* — Numeric room ID. Required when an event has multiple rooms. If omitted for an event with multiple rooms, the server returns `400 Bad Request`.

**`token`** *(string, optional)* — Alternative method to pass the JWT bearer token as a query parameter instead of using the `Authorization` header.

## Example Request

```bash
curl "https://voxbento.com/api/events/pycon2026/booths/en/state?room_id=14" \
  -H 'Authorization: Bearer eyJ...'
```

## Response Fields

**`booth_id`** *(string)* — Canonical booth identifier in `{event_slug}-{room_id}-{language_code}` format.

**`event_slug`** *(string)* — The event slug this booth belongs to.

**`language_code`** *(string)* — The ISO 639-1 language code for this booth channel.

**`instance`** *(string)* — Booth instance: `"primary"` or `"backup"`.

**`mediamtx_path`** *(string)* — MediaMTX stream path in `{event_slug}/{room_id}/{language_code}` format.

**`room_id`** *(integer | null)* — Numeric room ID.

**`language`** *(string)* — Human-readable language name, e.g. `"English"`.

**`channel_id`** *(string)* — Stream channel path (identical to `mediamtx_path`).

**`active_interpreter_id`** *(string | null)* — Participant ID of the interpreter currently authorized to publish audio, or `null` if idle.

**`handoff_state`** *(string)* — Live booth handoff state: `"idle"`, `"offered"`, or `"requested"`.

**`handoff_initiator_id`** *(string | null)* — Participant ID of the interpreter who initiated the handoff, or `null` if idle.

**`broadcast_unlocked`** *(boolean)* — Whether the broadcast lock is lifted.

**`ingest_status`** *(string)* — Live stream publishing status: `"connected"` if any participant is actively publishing WebRTC audio, otherwise `"disconnected"`.

**`participants`** *(array)* — List of participant objects currently connected to the booth WebSocket.

<details>
<summary>Participant object fields</summary>

**`participant_id`** *(string)* — Unique participant session identifier.

**`display_name`** *(string)* — Participant display name.

**`role`** *(string)* — Granted role for this participant (e.g. `"interpreter"`, `"coordinator"`, `"event_admin"`, `"super_admin"`, or `"listener"`).

**`language`** *(string)* — Language code assigned to this participant.

**`channel_id`** *(string)* — MediaMTX channel path.

**`mic_active`** *(boolean)* — Whether participant's microphone is unmuted.

**`ingest_connected`** *(boolean)* — Whether WebRTC WHIP publisher connection is active.

**`connected`** *(boolean)* — Whether WebSocket connection is active.

**`joined_at`** *(string)* — ISO 8601 UTC timestamp when participant joined.

**`updated_at`** *(string)* — ISO 8601 UTC timestamp of last participant update.

**`role_label`** *(string)* — Human-readable display label for the role (e.g. `"Interpreter"`).

**`can_go_live`** *(boolean)* — Whether this participant's role is permitted to publish live audio.

**`can_set_active`** *(boolean)* — Whether this participant is permitted to designate the active interpreter.

</details>

**`chat_messages`** *(array)* — Recent chat history (last 100 messages) in chronological order.

<details>
<summary>Chat message object fields</summary>

**`message_id`** *(string)* — Unique message identifier.

**`sender_id`** *(string)* — Participant ID of the message sender.

**`sender_name`** *(string)* — Display name of the sender.

**`body`** *(string)* — Text body of the message (maximum 1000 characters).

**`sent_at`** *(string)* — ISO 8601 UTC timestamp of message dispatch.

</details>

## Error Responses

| Status | Condition |
|---|---|
| `400 Bad Request` | Invalid `event_slug` or `language_code` format, or event has multiple rooms and `room_id` was omitted. |
| `403 Forbidden` | Bearer token is missing, invalid, or caller lacks booth view permissions. |
| `404 Not Found` | No booth for the specified language exists in memory or the database for this event, or event was not found. |

:::info
Booth state is served from active memory. If a requested booth exists in the database but is not currently active in memory, the endpoint automatically hydrates and snapshots the booth from the database.
:::
