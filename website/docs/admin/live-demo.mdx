The home page has a **Your voice** demo: a visitor presses the microphone, speaks, and
sees live captions, translations into up to three languages, and hears one of them read
aloud. It runs on the server's own models (Whisper for speech, NLLB for translation and
Supertonic for the voice), so it uses no provider keys but does use the server's CPU.

Admins manage it at **Admin → Live demo** (`/admin/live-demo/`).

## Turning it on and off

Untick **Show the live demo on the home page** and save to close it. The home page then
shows only the recorded demo, and new tries are refused; tries already running finish
normally. Tick it again when the server has room.

A server that should never run it can set `LIVE_DEMO_ENABLED=false`; the page then says
the demo is off on this server, whatever is saved.

## Limits

| Setting | What it does |
| --- | --- |
| Visitors at once | Tries running at the same time. Others are asked to try again in a minute. |
| Time limit per try | Longest single try, in seconds. |
| Tries per visitor per hour | Counted per network address. |
| Languages per try | How many languages a visitor can translate into. Each one adds a translation for every sentence. |
| Speech recognition model | Tiny is fastest, Small most accurate. Base suits most CPUs. |
| Speak the translations aloud | Turn off to save CPU; captions and translations keep working. |

## Site glossary

The site glossary is used in every try. Speech recognition listens for its terms, and the
translations keep them or use the translation you set. Write one entry per line:

```text
# Kept exactly as written, in every language
VoxBento
Eventyay

# The same translation in every language
keynote = plenary session

# Only in French (two-letter language code)
keynote = fr: séance plénière
```

A language-specific line wins over an every-language line for the same term. Visitors can
add their own names and translations in the demo; theirs win over the site glossary for
their try. Glossary terms are highlighted in the captions.

## Loading the models

The first try after a restart loads the models, and the very first one downloads about
1 GB. Press **Load models now** after deploying or changing the speech model so the first
visitor doesn't wait.
