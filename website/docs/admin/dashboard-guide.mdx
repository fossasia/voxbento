Voxbento organizes its management interfaces into clear, privilege-scoped surfaces:

- **`/admin/...`** — Reserved for `super_admin` users. Central hub for global platform administration, registered users, hosting access reviews, and developer application approvals.
- **`/workspace/...`** — The Event Workspace for `event_owner` users. Houses **My events**, event/room/booth configuration, invite tokens, members, and API settings.
- **`/mission-control/...`** — The operational console for `room_coordinator` users to oversee active broadcasts, monitor audio status, and conduct interpreter handoffs.

## 1. Global Header and Navigation

Every signed-in page renders a unified header with area links and a user profile menu:

- **My events (`/workspace/`)**: Lists every event you participate in or own with direct action links ("Event owner", "Room coordinator", "Enter booth"). Users with hosting access or admin rights see the **New event** button.
- **Hosting access (`/admin/hosting-access/`)**: (Admins only). Review and approve/decline event hosting access requests, with a badge showing the number of open requests.
- **Users (`/admin/users/`)**: (Admins only). Search and filter registered accounts, toggling **Hosting access**, **Admin**, **Active**, and **Verified** status directly in-place.
- **Developer API**: Direct access to registered OAuth applications and webhook management for approved developer accounts.
- **Account (`/account`)**: Manage display name, hosting access requests, developer status, and password sign-in settings.

## 2. Event Summary Cards

On the main dashboard and My events pages, each event is displayed as an actionable card:

- **Live Booths Metric**: Real-time count of booths currently broadcasting audio.
- **Rooms & Booths Count**: Overview of configured stages and language channels.
- **Action Buttons**: Direct links to **Manage event** (`/workspace/events/{id}`), **Mission Control** (`/mission-control/`), or **Enter booth**.

## 3. System Health Diagnostics

At the top of the dashboard, critical health status is displayed:

- **MediaMTX Reachable (Green)**: The portal communicates normally with the MediaMTX media server. WHIP ingest and WHEP playback are functional.
- **MediaMTX Unreachable (Red)**: The portal cannot contact MediaMTX. **Interpreters will not be able to go live.** Check container status.

## Role-Based Access Scoping

Voxbento enforces role separation at every route:

- **`super_admin`**: Full system-wide visibility. Access to `/admin/*`, user management, and hosting access approval.
- **`event_owner`**: Manages assigned events in `/workspace/*`, creating rooms, booths, API keys, and invite tokens.
- **`room_coordinator`**: Scoped operational oversight via `/mission-control/*` for assigned rooms and stages.
