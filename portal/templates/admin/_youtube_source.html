How does video reach YouTube?

Pick the route that matches your setup. Each one gets audio to VoxBento differently.

Set up forwarding

VoxBento receives your encoder stream and forwards it to YouTube unchanged. You keep one output, one upload.

Add VoxBento as an extra destination

In your streaming platform, add a Custom RTMP destination with the server URL and stream key shown below after you enable ingest.

Platform-specific guides
  • StreamYard: Destinations → Custom RTMP → paste the server and key.
  • Restream: Channels → Add channel → Custom RTMP → paste the server and key.
  • Zoom: Settings → In Meeting → Allow live streaming → Custom live streaming service → paste.

Share the stream's browser tab

Open the YouTube stream in a browser tab, then open the sender page below and share that tab's audio.
