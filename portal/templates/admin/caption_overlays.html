Changing the controls updates this preview and URL. Paste the new URL into your streaming software to apply the changes.

Set up in vMix or OBS
  1. Choose a room and language above. Enable its transcription or translation, and connect live audio. Live captions appear while broadcasting.
  2. vMix: Add Input → Web Browser. Paste the URL, set Width to 1920 and Height to 1080, then choose OK. Use an Overlay button (1–4) on that input to place captions over your video.
  3. OBS: Sources → + → Browser. Paste the URL, set Width to 1920 and Height to 1080, and place the source above your video. Keep “Shutdown source when not visible” off for continuous captions.
  4. Speak into the selected source and confirm captions on the output before going live. The page is transparent and carries no audio; no chroma key is needed.

Keep overlay URLs private: the included join code also grants listener access to the event. Regenerating the event join code requires replacing saved URLs. If captions stop, check the source audio and transcription, then refresh the browser input.
