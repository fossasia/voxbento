Site glossary

Used in every visitor's try, together with the names and translations they add themselves. Speech recognition listens for these terms, and translations keep them or use the translation you set.

VoxBento keeps a term as it is in every language. keynote = plenary session uses that translation in every language. keynote = fr: séance plénière uses it only in French (two-letter language code). Lines starting with # are ignored. Up to 100 entries.
